首次上电先断开外设和屏幕，用限流 5 V 确认 3.3 V，分开测 USB 与 J1 供电，再测 USB 正反插烧录、屏幕与触摸、滚轮和两路业务 UART；传感器贴装后读 `0x18`、`0x10` 并合壳检查光感。

本次以在线 P1、PCB1 和同次导出的 Gerber 为准。原生工程包的 PCB 器件、焊盘网络、过孔、板框、禁铜及走线几何与在线数据匹配；包中另有一条已无对应铺铜区域的历史缓存记录。复核脚本：安装 Shapely 2.x 后运行 `python run_review.py`。Gerber、BOM、CPL 均应以最终 DFM 审核后的同一版本为准。
