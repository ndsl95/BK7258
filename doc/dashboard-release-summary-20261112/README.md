# BK7258 三页仪表固件总结

日期：2026-11-12。项目：`code/projects/wb5e_lvgl`。台架使用 WB5E / BK7258、360 × 360 ST77916 圆屏和 CST816D 触摸。本文记录已编译并烧录的版本；它接续[触摸修复与三页展示版](../dashboard-touch-summary-20261112/仪表触摸与三页切换修改总结.md)。

## 页面与手势

| 页面 | 当前功能 |
| --- | --- |
| 1 · 仪表首页 | 保留开机扫表、指针、数字、灯光及电压/电流显示。在 `km/h` 右侧增加蓝牙状态图标，可点按打开蓝牙设置。灰色为未绑定，琥珀色为连接或等待重试，绿色带勾为已连接，红色带叉为连接失败。 |
| 2 · 保护板数据 | 保留原来的 32 串单体电压、总压、SOC、电流和压差界面。本版仍显示模拟数据。 |
| 3 · 蓝牙设置 | 显示绑定和连接状态，可搜索、确认绑定或换绑、手动重连及确认解绑。 |

以屏幕文字正立为准，向左滑按 **1 → 2 → 3 → 1** 循环，向右滑按反方向循环。松手时，横向净位移须至少 40 px，且至少为纵向位移的 1.5 倍；点按、纵滑和取消的触摸不会切页。滑动使用配置为 180 ms 的横移动画，点图标和串口指定页码可直接切换。

## 蓝牙绑定与恢复

- 绑定成功后，把地址、地址类型和名称保存到 AP EasyFlash。开机时尝试连接已保存的保护板；失败后等待 5 秒再试，最多额外重试 3 次，随后停止自动尝试并显示失败。
- 已连接时仍可搜索新保护板。确认换绑后先释放旧链路；新设备通过服务检查并成功保存后，才替换旧绑定。换绑失败则保留原记录，并尝试恢复原连接。
- 确认解绑会断开保护板、清除保存的绑定，并停止自动重连，便于其他设备连接。
- 扫描识别名称带 `ANT` / `BMS` 或广播 `FFE0` 的候选；连接后检查 `FFE0` 服务下的通知与写入特征。当前实现只验证链路与服务，尚未接入保护板数据读取。

## 切页时的动画与任务

确认切页后，两页内容在横移期间保持不变，只有页面位置在动。停在第 2 或第 3 页时，首页停止绘制读数，AP1 的仪表演示停止周期计算；开机扫表、转向灯和指针、电压、电流过渡保留暂停时的进度。返回首页并完成切页后，从原进度继续。

AP0 负责 LVGL，AP1 的仪表演示与 BLE 服务各自运行。首页暂停不影响 BLE 扫描、连接或重连；滑动结束后，界面再显示蓝牙的最新状态。

## 验证与复验

| 验证 | 结果 |
| --- | --- |
| 编译、打包和烧录 | AP/CP 构建通过，AP Flash 使用率 96.36%。COM11 烧录校验全部通过并自动重启。 |
| 实板切页 | 从串口走与触摸共用的切页路径，验证左右各循环一圈和直接切页。六次横移及停留在其他页时，仪表数据应用计数均保持不变。三次暂停约 3.47、3.34、1.33 秒，期间无新的随机演示读数；返回时演示时钟与离开时相同，随后继续更新。 |
| BLE 状态机 | 用主机假时钟、BLE 回调和 Flash 替身验证了 5 秒重试及停止、连接中扫描、换绑失败保留旧记录、成功换绑后重启回连、解绑后重启不回连。 |
| 仍待验证 | 此版未用手指复测滑页，也未用实体保护板测试扫描、绑定和断线重连。两页早期版本已单独在实屏验证过触摸。 |

台架复验使用 COM11、115200。发送 `ap_cmd dash_swipe left` 或 `ap_cmd dash_swipe right` 可模拟滑动，`ap_cmd dash_page 1|2|3` 可直接切页。比较 `DASH_SLIDE_START` 与 `DASH_SLIDE_DONE` 的 `samples`，以及 `DASH_HOME_ANIM` 暂停和恢复的 `phase_ms`。用 `ap_cmd dash_test 4` 启动演示，用 `ap_cmd dash_test 0` 停止。实板验证结束后留在首页，演示已开启；持续演示不会跨重启保存。
